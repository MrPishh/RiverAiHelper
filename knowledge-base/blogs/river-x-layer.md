### **X Layer and River**

**X Layer** is designed as an execution environment within the OKX ecosystem. It anchors users and assets in a wallet-native on-chain setting built for consistent, repeatable activity.

River approaches the same direction. 

River is building a chain-abstraction stablecoin system that connects assets to their opportunities across ecosystems. This integration aligns the two systems through clear functional roles. 

X Layer defines where assets are executed.River connects assets and activates liquidity across ecosystems.

### **What River Enables on X Layer**

With River live on X Layer, assets held within the OKX ecosystem can participate in a broader range of on-chain activities through a unified system.

**Stablecoin minting**

Users on X Layer can get satUSD through:

-   Deposit wBTC or wETH as collateral to mint satUSD
-   Swap USDT or USDC for satUSD at a 1:1 ratio

This converts existing assets into stable liquidity while maintaining underlying asset exposure.

**Yield participation**

satUSD can be staked to receive **satUSD+**.

satUSD+ represents a yield-bearing stablecoin position backed by protocol revenue and active DeFi deployment across River-supported ecosystems. Yield accrues from system usage rather than incentive emissions.

**Cross-ecosystem liquidity deployment**

satUSD minted on X Layer is compatible with River’s native chain-abstraction architecture. Stable liquidity can be deployed across multiple ecosystems while remaining anchored to X Layer as the execution environment.

### **How to Use River on X Layer** 

Using River on X Layer follows a straightforward flow:

1.  Go to [https://app.riverai.inc/](https://app.riverai.inc/?ref=blog.riverai.inc)
2.  Switch the network to **X Layer**
3.  Deposit **wBTC or wETH** 
4.  Mint **satUSD**
5.  Stake satUSD to participate in yield
6.  Use satUSD across supported ecosystems

You can also swap USDT / USDC for satUSD at 1:1 ratio
